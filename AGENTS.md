# Plug_Blender

Репозиторий `maxrus82gm-svg/Plug_Blender` — AI-помощник для 3D-моделирования в Blender. Подтверждённое состояние хранится в [Documentation/](Documentation/00_Главная.md).

Перед работой прочитай активную TASK (`Documentation/11_Задача_агенту.md`) и START (`Documentation/12_Старт_агента.md`); остальные документы выбирай по его маршрутам.

- Выполняй текущую TASK до логического завершения внутри её scope. Её актуальные указания имеют приоритет над устаревшим перенесённым контекстом.
- Мелкие пробелы закрывай разумно по задаче, фактическим файлам и подтверждённым решениям. Спрашивай, когда ответ существенно меняет результат; независимую безопасную часть продолжай.
- Подтверждённую архитектуру не меняй самовольно. Подробности автономности, ролей и проверок: правила агента (`Documentation/10_Правила_агента.md`).
- Git контролирует пользователь: destructive и изменяющие Git-действия требуют прямого разрешения. Пользовательские изменения сохраняй. Полный порядок: Git и review (`Documentation/20_SplitDoc/GIT_REVIEW_RULES.md`).
- Сообщай только фактически выполненные проверки и их ограничения. Выполнение задачи не означает её принятие; завершение и review описаны в START.

Правила ведения документации и кодировки выбираются через SplitDoc (`Documentation/20_SplitDoc/00_INDEX.md`), концепция проекта — через Project_Docs (`Documentation/21_Project_Docs/00_INDEX.md`).

# 20_SplitDoc — тематические правила

SplitDoc содержит постоянные правила по отдельным темам. Они читаются выборочно по матрице в Documentation_CPP_UE/11_Задача_агенту.md.

## Документы

- [DOCUMENTATION_RULES](DOCUMENTATION_RULES.md) — создание, перенос и изменение документации.
- [ENCODING_RULES](ENCODING_RULES.md) — UTF-8, кириллица и безопасная работа с текстом.
- [GIT_REVIEW_RULES](GIT_REVIEW_RULES.md) — Git, GitHub, diff, review и пользовательские изменения.
- [TASK_HISTORY](TASK_HISTORY.md) — подтверждённая история задач новой системы.
- [UNREAL_PROJECT_RULES](UNREAL_PROJECT_RULES.md) — осторожная работа со структурой Unreal Engine проекта.
- [UNREAL_CPP_RULES](UNREAL_CPP_RULES.md) — минимальные безопасные правила Unreal C++.

## Принцип

- Не читать все документы подряд без необходимости.
- Не создавать новый SplitDoc, если правило естественно помещается в существующий.
- Одно постоянное правило имеет один канонический источник.
- Предметные факты конкретного проекта после проверки помещаются в Documentation_CPP_UE/21_Project_Docs/.

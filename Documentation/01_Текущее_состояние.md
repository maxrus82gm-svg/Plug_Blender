## Реализация

Создан минимальный Astro Modeler: устанавливаемый add-on в `Plugins/AstroModeler/astro_modeler/`, внешний STDIO MCP server в `MCP/` и проверки в `Tests/`. Доступны четыре public tools: `create_cube()`, read-only `get_selected_context()` с прежними контрактами `create_box_at_cursor(size_x, size_y, size_z)` и `post_modeling_note(status, summary, details="")`. Контракты Box / Agent Feedback и подтверждённые проверки — в `Documentation/04_Архитектура.md`, разделы Geometry Placement v1 / Agent Feedback v1.

Selected Context v1 возвращает name/type active object, выбранные объекты с мировым transform 3 × 4, mode и 3D Cursor с позицией/quaternion. Матрица компактно сохраняет pivot, local axes, scale, parenting/shear/reflection без дублирующих представлений. Полный контракт — в `Documentation/04_Архитектура.md`. Геометрия Mesh не читается и не сериализуется.

Blender явно регистрирует одну сессию кнопкой Start Integration. Локальный socket обслуживается неблокирующим таймером Blender; `bpy` не вызывается из фонового Python thread. Технические решения прототипа записаны в `Documentation/02_Решения.md` и `Documentation/04_Архитектура.md` и не объявлены production architecture.

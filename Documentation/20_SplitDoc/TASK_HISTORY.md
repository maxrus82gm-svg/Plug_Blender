## 2026-09-05 — TASK 003 — Astro Modeler: Minimal Blender MCP Vertical Prototype

**Цель:** реализовать первую цепочку Codex → MCP → Astro Modeler → открытый Blender → Create Cube.

**Сделано:** создан минимальный installable add-on, внешний STDIO FastMCP server и loopback bridge с одной явно зарегистрированной сессией. Единственный public tool — `create_cube()`. `bpy` исполняется таймером Blender без фоновых Python threads. Подготовлены project-local dependencies, ZIP, проверки и инструкция установки. В START закреплён универсальный протокол «Большой блок + Малый блок». По отдельному уточнению пользователя добавлено одно ребро SplitDoc INDEX → `Documentation/Codex_Решение_Проблем.md`.

**Проверки:** восемь socket/protocol tests, SDK STDIO discovery/error smoke, два реальных MCP-вызова установленного Codex app-server в GUI Blender 5.0.1. Созданы `Cube.001` и `Cube.002`; имена и геометрия подтверждены сценой и независимым чтением `.blend`. ZIP install/enable, stop/restart/disable, отключение после загрузки файла и отказ в Edit Mode проверены в изолированном Blender окружении.

**Ограничения первоначальной проверки:** app-server проверен без модельного turn; рабочая пользовательская сессия тогда не использовалась, тестовая GUI session закрыта после сохранения результата. Позднее ручной пользовательский сценарий подтверждён, как указано в итоге review ниже. Сохранённые MCP settings агент не менял; изменения `.obsidian` и пользовательский документ не перезаписывал. Архитектура остаётся прототипом.

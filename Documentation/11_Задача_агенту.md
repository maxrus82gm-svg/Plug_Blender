**ARCHITECTURE CHOSEN:** Codex → STDIO → внешний FastMCP process → локальный TCP bridge → `bpy.app.timers` → Blender main thread → Scene. STDIO даёт запуск MCP силами клиента, внешний process оставляет зависимости SDK вне Blender; неблокирующий bridge требует только стандартной библиотеки. Embedded MCP / HTTP не понадобились для одной операции. Это локальный обратимый выбор TASK 003, а не окончательная production architecture.

**SESSION CONNECTION MODEL:** одна явно подключённая сессия. Start Integration эксклюзивно занимает `127.0.0.1:55881` и атомарно записывает endpoint/token во временный каталог ОС. Вторая сессия получает ошибку порта; process discovery и session selection отсутствуют. Stop Integration, disable add-on и загрузка другого `.blend` снимают timer, закрывают sockets и удаляют свой descriptor. При аварийном завершении устаревший descriptor заменяется следующим успешным запуском.

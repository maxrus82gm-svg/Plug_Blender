**РЕАЛИЗОВАНО:** native секция `АНАЛИЗ МОДИФИКАТОРОВ` работает по flow: active selected object в Object Mode → `Получить модификаторы` → выбрать один modifier → `Сравнить параметры`. Python фиксирует object identity, stack index, имя, type и runtime reference выбранного modifier, создаёт временный незалинкованный object с freshly-created modifier того же type в том же running Blender, exact-сравнением находит только изменённые поддерживаемые RNA properties и удаляет собственные временные datablocks. Удаление исходного modifier инвалидирует reference, поэтому новый modifier с теми же index/name/type отклоняется как stale.

**DETERMINISTIC CONTRACT:** RNA `Property.default` не используется как source of truth. Diff вычисляется локально без AI; полный modifier dump модели не отправляется. V1 сравнивает только один current modifier с freshly-created default текущей версии Blender. Object-vs-object, snapshots и Analyze All не реализованы. Возможный dirty `.blend` остаётся принятым V1 limitation.

**AI EXPLANATION:** public read-only MCP tool `inspect_selected_modifier_changes()` читает только уже подготовленный актуальный compact diff. Объяснение отделено от Compare и необязательно; пустой context получает стандартную русскую инструкцию. Модель должна объяснять доказанные Python facts и помечать предполагаемое намерение автора как вероятность. Reverse Blender → Codex transport и AI Response window не реализованы.

**PUBLIC MCP CONTRACT:** публичных tools ровно пять: `create_cube`, `get_selected_context`, `create_box_at_cursor`, `post_modeling_note`, `inspect_selected_modifier_changes`. Существующие modelling capabilities не расширялись.

## Следующий выбранный приоритет

**Blender AI Interaction / Response Panel** — начать с архитектурного исследования безопасного request/response transport для вопроса из Blender, ответа модели и его отображения в отдельной Blender UI. Направление выбрано следующим, но новая TASK ещё не создана и не запущена. Канонический handoff находится в `Documentation/13_Приоритетная_задача.md`.

## Будущие кандидаты

### Local Thickness Inspection

Локальное детерминированное измерение толщины остаётся будущим кандидатом. Реализация и номер TASK не утверждены; автоматически не запускать.

### Переиспользуемая runtime test infrastructure

Общая изолированная Blender runtime fixture и переиспользуемые сценарии могут сократить стоимость проверки новых tools. Отдельная реализация и номер TASK не утверждены.

### Modifier Inspector — будущие режимы

Object-vs-object, snapshots и Analyze All остаются возможными расширениями после V1. Они не входят в закрытую TASK 016 и не запускаются автоматически.

# Очередь задач Plug_Blender

Очередь содержит предложения для следующих TASK. Запуск, нумерация и review регулируются [START](12_Старт_агента.md); выполненная работа хранится в [TASK_HISTORY](20_SplitDoc/TASK_HISTORY.md).

## TASK 002 — Исследовать минимальный Blender MCP vertical prototype

**Цель:** определить минимальную жизнеспособную архитектуру, при которой Codex через MCP сможет вызвать одну контролируемую Blender operation — Create Cube.

**Тип:** исследование / технический анализ.

**Ожидаемый результат будущей постановки:** сравнить необходимые варианты связи, предложить минимальный проверяемый путь и условия реального теста Create Cube. Конкретный scope реализации должен быть определён отдельно при постановке TASK 002.

**Статус:** в очереди; не запущена и не выполнялась в TASK 001.

После успешного Create Cube предусмотрен следующий тест — получить список объектов Blender Scene и определить текущий selected object. Полный modelling toolkit не входит автоматически в этот шаг.

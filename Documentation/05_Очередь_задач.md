## TASK 003 — Astro Modeler: Minimal Blender MCP Vertical Prototype

**Цель:** реализовать и проверить минимальную цепочку Codex → MCP → открытый Blender → Create Cube.

**Тип:** исследование + минимальная реализация + runtime-проверка.

**Результат:** Astro Modeler add-on, внешний MCP server, один `create_cube`, два подтверждённых вызова из установленного Codex app-server в GUI Blender, installable ZIP и инструкция. Ограничения проверки обычного диалога приведены в отчёте и `Documentation/21_Project_Docs/ASTRO_MODELER_SETUP.md`.

**Статус:** исполнение завершено; ожидается review. TASK 003 не объявлена PASS агентом.

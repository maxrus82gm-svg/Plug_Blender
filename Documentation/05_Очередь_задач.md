# Очередь задач Plug_Blender

Очередь содержит предложения для следующих TASK. Запуск, нумерация и review регулируются START (`Documentation/12_Старт_агента.md`); выполненная работа хранится в `Documentation/20_SplitDoc/TASK_HISTORY.md`.

## TASK 003 — Astro Modeler: Minimal Blender MCP Vertical Prototype

**Цель:** реализовать и проверить минимальную цепочку Codex → MCP → открытый Blender → Create Cube.

**Тип:** исследование + минимальная реализация + runtime-проверка.

**Результат:** Astro Modeler add-on, внешний MCP server, один `create_cube`, два подтверждённых вызова из установленного Codex app-server в GUI Blender, installable ZIP и инструкция. После этого пользователь подтвердил обычный текстовый Codex → MCP → Astro Modeler → рабочий Blender → Cube.

**Статус:** PASS по прямому указанию пользователя после ручного end-to-end теста; итог синхронизирован в TASK_HISTORY.

## TASK 004 — Зафиксировать направления развития Astro Modeler

**Результат:** read-only `get_selected_context()` для выбранных/active объектов, их мирового transform/local axes и 3D Cursor. Принцип компактных результатов закреплён; тяжёлая геометрия не передаётся. Реальный Blender/MCP/Codex app-server test и regression Create Cube пройдены. Полный список Scene из раннего предложения не вошёл в уточнённый scope пользователя и не реализован.

**Статус:** окончательный PASS по внешнему INDEPENDENT REVIEW, переданному в TASK 006 после ручного теста в рабочем Blender; итог синхронизирован в TASK_HISTORY.

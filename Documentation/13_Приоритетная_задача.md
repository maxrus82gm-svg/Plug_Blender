# Следующая приоритетная задача

## Blender AI Interaction / Response Panel

Следующая задача должна начаться с архитектурного исследования безопасного request/response transport для Blender-initiated AI interaction.

Целевой пользовательский flow:

1. Пользователь вводит вопрос или запрос внутри Blender.
2. Запрос получает модель.
3. Ответ модели возвращается в Blender.
4. Ответ остаётся читаемым в отдельной удобно размещаемой и настраиваемой области или панели.

До реализации UI нужно определить, кто принимает запрос, как он попадает модели и связывается с ответом, где живут chat/session state, как transport сочетается с текущим STDIO MCP и как исключить arbitrary Python и unsafe bypass. Обычная кнопка Blender не считается заранее способной отправить сообщение в существующую Codex conversation.

AI response UI остаётся отдельной подсистемой и не смешивается с Agent Activity HUD, Agent Feedback Log или deterministic result Modifier Inspector. Modifier Inspector в этой задаче не расширяется. Конкретная форма панели ещё не выбрана.

Общая очередь `Documentation/05_Очередь_задач.md` остаётся backlog будущей работы; этот файл хранит только текущий следующий handoff и заменяется при смене приоритета.

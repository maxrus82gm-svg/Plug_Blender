# Открытые вопросы Plug_Blender

Все вопросы ниже открыты на завершение TASK 001. Перечисленные варианты не являются выбранными решениями. Исследование ближайшего минимального шага предложено в [очереди](05_Очередь_задач.md).

| Область | Что определить | Почему это важно |
| --- | --- | --- |
| Blender | Конкретная версия и среда первого теста | Воспроизводимость прототипа и совместимость API |
| MCP | SDK/framework и Python MCP library, если она потребуется | Зависимости и минимальная реализация сервера |
| Codex ↔ MCP | STDIO, HTTP или другой допустимый transport | Запуск и подключение MCP-клиента |
| MCP ↔ Blender | Встроенный server, addon как bridge, внешний process или их сочетание | Границы процессов и жизненный цикл интеграции |
| Локальная связь | Socket, HTTP или иной local IPC; нужны ли ports и какие | Доставка команд между выбранными частями |
| Исполнение | Thread model, взаимодействие с Blender main thread и механизм исполнения операций | Корректное изменение сцены |
| Controlled tools | Как проверять параметры, разрешать операции и сообщать ограничения; минимальный tool set после прототипа | Контролируемый интерфейс модели |
| Arbitrary Python | Ограничения, условия допуска и границы `execute_blender_python` | Безопасность дополнительного escape hatch |
| Scene state | Формат списка объектов и selection; active object, несколько выбранных объектов и пустое выделение | Однозначный результат чтения сцены |
| Ошибки и изменения | Error handling, частичный результат, undo/transactions | Восстановление после неудачной операции |
| Упаковка | Packaging, запуск, установка и обновление | Воспроизводимое использование пользователем |
| Исходники | Структура Python packages, source directories, модули и классы | Организация кода после выбора минимальной архитектуры |
| Feedback | Механизм viewport/render feedback и screenshots | Наблюдение результата и итерационное исправление |
| Референсы | Передача изображений и чертежей, масштабы и недостающие размеры | Работа по визуальному заданию |
| Модель и API | Конкретный технический режим Astra; понадобится ли когда-либо прямой OpenAI API | Требования будущих сценариев сверх исходного направления |

Не требуется отвечать на весь список для первого прототипа. Будущая TASK должна выделить только вопросы, существенно влияющие на её результат. Подтверждённые ответы затем фиксируются в [решениях](02_Решения.md) и соответствующих проектных документах.
